# Royal Palace Marriage Hall

A responsive luxury website for Royal Palace Marriage Hall, managed by M. Ali.

## Features
- Responsive black-and-gold design
- Venue introduction and gallery
- Wedding and reception services
- Event enquiry form (prepares a message for the visitor to copy)

## Deployment
This is a static HTML/CSS/JavaScript site and can be deployed on Vercel with no build command. Set the output directory to the repository root.
